# 租务小程序隐私与提审准备

维护日期：2026-11-13。此文件是按当前实现编写的准备材料，尚未提交微信后台，也不是已生效的隐私政策。正式名称、运营主体、联系渠道、保留期限及类目选择须由账号主体核定；当前主体为个人，不能凭通用类目名称认定有发布资格。

## 功能与审核说明草稿

本小程序供已入住租客查询房东管理的本人租住资料、账单、线下实收记录与归档合同。租客首次使用微信登录并填写入住时使用的联系手机号，房东在管理后台核对后关联租户档案；关联前只显示等待页，不能读取业务数据。手填手机号不会自动认领资料，也不按同号合并已有账号。后续微信登录进入本人门户。

租客侧包含“首页、账单、合同、我的”四个入口，账单支持分页、费用明细和实收/冲销状态；“我的”可查看本人资料、进入缴费记录并退出。合同和归档单据需要登录鉴权后下载到应用专用本地目录，再调用微信原生查看器打开。房东第一阶段增加现有账号密码登录、台账切换、房源与账单查询；待审核账号不开放业务，管理员也仅访问本人获授权的台账。小程序不提供房东记账、在线支付、租赁撮合、公开房源交易或电子签约服务，业务写入继续在Web完成；房东可主动以当前密码确认绑定微信，之后快捷登录；解绑保留账号与业务并撤销全部应用JWT（含Web登录）。

本版仍缺少多房东来源/归属接入，该需求按用户指令暂缓。提审说明应如实写当前单次档案关联方式，不声称已支持多房东选择或多租约切换。

## 数据清单与隐私指引草稿

| 数据/能力 | 当前用途及来源 | 当前处理方式 |
|---|---|---|
| 微信一次性登录code | 确认微信账号身份 | 客户端交后端，由后端请求code2Session；不保存session_key，不返回OpenID作为登录凭据 |
| AppID/OpenID与应用账号关联 | 再次识别对应租客或主动绑定的房东账号 | 仅保存在服务端微信身份表；AppSecret仅受限服务端环境，不进入客户端或审核截图 |
| 房东现有账号与密码 | 认证已有房东/管理员业务账号 | 通过HTTPS调用已有认证接口，认证与绑定/解绑本人操作，不在小程序本地保存密码；提交绑定操作、隐藏页面/切号清理表单，只保存应用令牌和最小身份 |
| 房东台账、房源与账款资料 | 按已有成员及模块权限查询 | 服务器按当前台账授权；本地不离线缓存业务，切台账丢弃旧响应，撤权后刷新清理旧展示；不凭客户端自选身份获取其他台账资料 |
| 首次手填的手机号 | 供房东核对入住联系方式 | 用户输入，未调用微信手机号授权；不凭号码自动关联、合并或转移租户档案 |
| 姓名、房号、租期及档案字段 | 展示本人房东已登记的租住资料 | 通过绑定账号由服务器限定可见范围；当前档案可能含证件、联系方式及同住人资料，提审前须按实际响应/页面核实后台所填字段 |
| 应缴、实收、冲销与费用明细 | 查询本人账款记录 | 只读展示线下登记记录，不处理真实支付或退款；历史单据保留原件 |
| 合同PDF及上传的合同图片/文件 | 查看本人租赁文件 | 鉴权下载到微信应用专用文件目录，校验状态和文件头后打开；换文件、退出/切号、下次启动清理，并对清理失败保留重试索引 |
| 应用登录令牌与最小账号标识 | 保持登录 | 保存在微信本地存储，退出清除；页面隐藏/卸载清理业务展示，旧请求结果不能覆盖新账号 |
| 服务访问与审计日志 | 故障定位及操作追溯 | 服务端记录操作及必要上下文；最终隐私说明需核定具体保留期限与处理渠道，不把技术默认值当作运营承诺 |

本版没有新增广告、第三方统计SDK或客户端npm依赖；微信登录和原生文件查看由微信平台提供。业务后端现部署在华为云新加坡VPS，真实使用时的数据存储地点必须在最终隐私说明和适用的后台材料中如实核定，不能写成仅保存在用户手机或境内服务器。

可用于后台指引的说明草稿：

> 我们为账号登录、确认租客资料归属，以及展示本人租住资料或获授权台账的房源、账款信息处理所需数据。租客首次填写的手机号由房东核对后关联；填写相同手机号不会自动取得他人资料。房东使用现有账号密码认证，小程序不在本地保存密码。您可随时退出以清除本应用保存的登录状态和专用下载文件。原生查看器中另行保存、复制或转发的文件由您和微信管理。关于账号解除关联、资料更正、删除请求和投诉，请通过运营者公布的联系渠道提出；涉及合同与账款原始记录的保留安排由运营主体确认并告知。

“退出清理”不等于服务端删除账号或合同。当前没有承诺用户可以在小程序内一键删除全部服务端历史；不能在最终政策中虚构该功能。运营主体应确定联系渠道、请求处理流程、响应期限、备份处理方式和必要记录保留期限后再发布政策。

## 隔离审核演示流程

1. 使用独立演示实例和合成资料，提供可重复的房东确认关联步骤；不要向审核人员提供生产管理员密码或真实租客档案。
2. 首次微信登录→填写合成入住手机号→等待房东关联。因微信身份与设备绑定，不能直接把本机fixture令牌当成审核登录账号；上线前需为审核方准备实际可执行的关联方式。
3. 在独立演示Web中按小程序显示的账号名搜索并关联合成租户；重新进入小程序首页，查看本人房号、租期与最近账单。
4. 账单实际翻到第二页，查看单笔费用；“我的→缴费记录”查看实收与冲销；合同入口下载并打开有效PDF。
5. 退出后返回微信登录页，专用下载文件删除；换一个未关联账号仅显示等待页，不可读取前一账号业务。

此前已准备12张账单、12笔含冲销流水、净实收600/欠9000的租客合成场景，原生与Web均有证据。新增房东演示应使用独立合成账号验证：账密登录→本人台账→房源/账单查询及分页→切共享台账→退出；另展示待审核、只读成员与跨房东拒绝。新本地夹具为`.runtime/mini-landlord-20261113-01/`，回执见测试报告§14。这些临时夹具在收尾清理口令/令牌，不是长期审核服务；正式演示实例、审核方关联方式及外部访问地址仍待落实。
