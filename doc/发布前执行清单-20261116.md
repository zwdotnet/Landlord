### 3.1 先做源目录只读预检

```powershell

# 输出父目录须已存在且受限；输出文件须为新文件，并位于data之外。
python tools/migration-preflight.py --data-dir D:/Landlord-private/intake/data --offline --approved-copy --output D:/Landlord-private/evidence/intake-01.json
```

预检包括：两次目录指纹防变化、quick_check、声明外键检查、逐表行数、schema指纹，以及五类上传和三类待审核照片引用。拒绝缺件、越界/无效引用、符号链接/junction及常见配置/密钥文件，不输出路径、账号、行ID、字段值或原异常正文。JSON中的逐表计数及指纹仍作为本地受限回执，不据此批准上传；文件名规则检查不能发现任意内容中的敏感信息。
