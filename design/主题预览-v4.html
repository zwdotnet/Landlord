01设计上下文

使用者：小店店主，单手拿手机，常在收银台或仓库边走边记。环境光不定——室外强光、货架阴影、深夜关店后的暖灯。
核心任务：三秒内确认今天收了多少钱、还欠哪几家、这家欠多少。
因此本案的取舍：玻璃用于表达「什么浮在最上层」，绝不用于信息主体。凡是承载数字的表面，一律实心白底；只有导航栏、主卡、弹层允许半透明。

03玻璃配方

玻璃感最容易做坏的地方是「半透明方块 + 圆角 + 阴影」的三件套。真正让一块玻璃成立的是棱边—— 顶部一道内高光模拟光源，底部一道极细暗边模拟厚度，外部再落一层带蓝调的柔影。

层作用
inset 0 1px 0棱边顶部高光，玻璃的「受光面」
inset 0 0 0 1px内描边，让边缘在任意背景上都不糊
0 0 0 1px底部外暗边，交代玻璃的厚度
外部柔影用 rgba(24,28,60) 而非纯黑，阴影才像「光被挡」
另外加了两处细节：背景光斑全部压到 0.26–0.40 不透明度并模糊 44px，保证玻璃叠上去后最亮处仍有 5:1； 页面铺一层 2.8% 的噪点，让磨砂有物理颗粒感，这是它和数字渐变的分水岭。

05间距与圆角

07设计令牌

完整令牌已输出为同目录的 design-tokens.css，可直接引入。 下面是要改主题时唯一需要动的部分。 

/* 换主题只改这一层：语义令牌 */
:root {
  /* 表面与玻璃 */
  --mg-bg:            #F7F8FC;
  --mg-surface:       #FFFFFF;
  --mg-glass:         rgba(255,255,255,.66);
  --mg-glass-strong:  rgba(255,255,255,.78);
  --mg-glass-blur:    saturate(180%) blur(22px);
  --mg-glass-sheen:   rgba(255,255,255,.92);
  --mg-glass-edge:    rgba(20,22,31,.07);

  /* 文字 */
  --mg-text:          #14161F;   /* 17.5:1 */
  --mg-text-2:        #525770;   /* 6.5:1  */
  --mg-text-3:        #636980;   /* 5.0:1  */
  --mg-text-onfill:   #FFFFFF;

  /* 品牌与语义 */
  --mg-accent:        #5262DD;
  --mg-accent-quiet:  #F0F2FE;
  --mg-danger:        #CE3439;  --mg-danger-text:  #B92B31;
  --mg-success:       #1E7A4E;  --mg-warn-text:    #9E6200;

  /* 线条 */
  --mg-line:          #E4E7F0;
  --mg-line-strong:   #D2D7E4;
}

/* 用法示例 */
.floating-bar {
  background: var(--mg-glass-strong);
  backdrop-filter: var(--mg-glass-blur);
  box-shadow:
    inset 0 1px 0 var(--mg-glass-sheen),   /* 棱边高光 */
    0 0 0 1px var(--mg-glass-edge);        /* 棱边暗边 */
}
